How I validate AI-assisted delivery.

Much of my recent work is built with AI coding tools across several models, so my job is defining the requirement, reviewing the evidence, and deciding what ships. One recent run exited successfully, but its run evidence did not cover the acceptance criteria. It went to awaiting verification instead of done, and was reworked. A successful exit is not acceptance.

New tests must fail firstA test is only evidence if it failed against the unfixed code. Where it matters, a mutation check confirms the guard is what makes it pass.
Approvals bind to a commitInputs, commits, and run evidence are saved with every task. One more push, and the review starts over.
Execution success ≠ acceptanceQuality approval is never granted automatically. Tools have no production access; the merge and the release call are mine.
